# Track recipes

The theme already supplies the base style (heroic medieval fantasy, light orchestral,
warm cartoon adventure, live instruments). These prompts only say what is different about
the track. Generate longer than you need and cut the loop from the middle.

## Blending a genre in

Genre names steer hard and blend well with the base style. Worth reaching for when a
region needs its own identity:

- `celtic folk, fiddle and bodhrán` — highlands, druids
- `spaghetti western, twanging guitar and whistle` — badlands
- `baroque, harpsichord and chamber strings` — a noble court
- `sea shanty, accordion and stomping rhythm` — harbours

## Tuning

Order of influence, strongest first: instruments named, tempo and energy words, mood
adjectives. If a track is not landing, change the instruments before you change the
adjectives.

`--vocal` allows singing, but lyrics slur often enough that instrumental is the default
for anything shipping.
